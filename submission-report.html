3. Deep-Dive: Key CSS Concepts Applied (Modules 2, 4 & 5)

Tokens CSS Custom Properties

Over 35 structured :root variables define colors, elevation shadows (--shadow-md to --shadow-2xl), typographic stacks, and spring transitions. Enables seamless instant dark-theme re-skinning without refactoring markup.

Layout Flexbox & CSS Grid

Eliminated legacy floats and table hacks. Used CSS Grid for 2-column hero layouts, 3-column experience feeds, and responsive project grids. Flexbox handles micro-alignments: tag rows, badge icons, and navigation bar button clusters.

Motion Pure CSS Animations

Subtle, non-distracting hardware-accelerated animations: floating background ambient mesh orbs (@keyframes floatOrb), live status radar pulse, gradient text shimmering, and responsive card lift on hover (translateY(-4px)).

Accessibility Responsive Breakpoints & Motion Safety

4-tier responsive fluid hierarchy: Desktop (1400px), Laptop (1200px), Tablet (860px), and Mobile (520px). Features @media (prefers-reduced-motion: reduce) to honor vestibular safety by disabling ambient animations for sensitive users.

Selectors Advanced CSS Specificity

Demonstrated element, class, attribute ([data-theme="contrast"]), and pseudo-classes (:hover, :focus-visible, :nth-child(), :disabled) to maintain low specificity and modular cascade control.

4. JavaScript Integration Mapped Directly to Course Syllabus (Module 6)

Per the course transcript guidelines, interactive functionality was implemented using modern, standard ECMAScript in an external script (script.js), directly showcasing the core competencies taught in Module 6:

6.1 & 6.2 Fundamentals, Scope & Data Types

Enforced 'use strict';. Block scoping applied via const (for immutable DOM references, theme dictionaries, and regex patterns) and let (for mutable state such as currentThemeIndex and animation progress). Clear distinction between primitives (Number, Boolean, String) and reference types (Objects, NodeLists, Arrays).

6.3 & 6.4 Numbers, Math & Control Flow

Parsed numerical data attributes via parseFloat(). Used Math.pow() and Math.min() to calculate cubic ease-out acceleration for live count-up stats. Control flow handled using defensive if...else conditionals, truthy/falsy null guards, and concise ternary operators (progress = scrollH > 0 ? (sTop / scrollH) * 100 : 0).

6.5 & 6.6 Arrays, Objects & State Dictionaries

Managed theme state with configuration objects (THEME_CONFIG). Transformed DOM NodeLists into JavaScript Arrays using Array.from() to perform real-time project filtering using .filter() and .forEach(). Client-side form validation captures field discrepancies inside an extensible error object dictionary.

6.7 & 6.8 Loops, Functions & DOM Event Listeners

Employed modern for...of loops for clean iteration over DOM elements. Modular architecture utilizes pure functions with explicit parameters and return values. DOM listeners handle 'scroll', 'click', 'submit', and mouse tracking for interactive 3D card tilt and copy-to-clipboard toast feedback.

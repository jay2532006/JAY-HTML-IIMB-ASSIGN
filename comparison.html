1️⃣ Assignment Step 2.1

Typography & Theme Personality

Implemented

Requirement: "Choose fonts that reflect the theme or personality of your site."

❌ Before (Step 1 Unoptimized HTML)

Relied entirely on browser default serif fonts (Times New Roman on Windows, Times on Mac). Lacked hierarchy, weight definition, and numerical alignment for financial analytics.

/* No custom fonts declared */ body { font-family: initial; } h1, h2, h3 { font-family: serif; }

✅ After (Step 2 Enhanced CSS)

Curated three complementary Google Fonts: Syne (bold tech/modern display headlines), Plus Jakarta Sans (high-legibility executive body), and JetBrains Mono (precise tabular numbers and technology tags). Fluid scaling via clamp().

--font-display: 'Syne', sans-serif; --font-body: 'Plus Jakarta Sans', sans-serif; --font-mono: 'JetBrains Mono', monospace; .hero-title { font-size: clamp(2.6rem, 5.5vw, 4.8rem); }
2️⃣ Assignment Step 2.2

Consistent & Visually Appealing Color Palette

Implemented

Requirement: "Apply a color palette that is consistent and visually appealing."

❌ Before (Step 1 Unoptimized HTML)

Default white background (#ffffff), black text (#000000), harsh blue unvisited hyperlinks (#0000ee), and purple visited hyperlinks (#551a8b). No visual warmth or branded identity.

<body bgcolor="#ffffff" text="#000000"> <a href="...">Default Blue Link</a> </body>

✅ After (Step 2 Enhanced CSS)

Engineered an Obsidian Ink & Champagne Gold executive color system with CSS custom properties (:root). Dark slate depth (#0a0a0e), warm gold accents (#c8a882), ivory text (#f5f1e8), subtle translucent border tokens, and ambient radial glow orbs.

:root { --bg-black: #060608; --bg-surface: #101015; --accent-gold: #c8a882; --text-primary: #f5f1e8; --border-highlight: rgba(200, 168, 130, 0.35); }
3️⃣ Assignment Step 2.3

CSS Selectors Taxonomy (Class, ID, Element, Pseudo)

Implemented

Requirement: "Use CSS selectors (class, ID, and element selectors) to organize your styling efficiently."

❌ Before (Step 1 Unoptimized HTML)

Zero class selectors or ID-based styling rules. Relied purely on basic unstyled element tags and outdated inline table attributes (border="1" cellpadding="6").

<table border="1" cellpadding="6" cellspacing="0" width="100%"> <tr bgcolor="#f0f0f0"><th>...</th></tr> </table>

✅ After (Step 2 Enhanced CSS)

Structured CSS selector taxonomy across multiple specificity levels:
• Element selectors: body, h1, p, section
• Class selectors: .btn-primary, .project-card, .stat-card
• ID selectors: #dossier-overview, #dossier-builds
• Pseudo-classes & elements: :hover, :focus-visible, ::after, ::selection

/* Combinator & Pseudo Selectors */ .nav-link::after { content: ''; width: 0; transition: width 0.2s; } .nav-link:hover::after { width: 100%; } .project-card:hover { transform: translateY(-4px); }
4️⃣ Assignment Step 2.4

Display & Positioning Properties (Flexbox, Grid, Sticky, Fixed)

Implemented

Requirement: "Try out display and positioning properties to structure your site — add a navigation bar, feature sections, or cards if needed."

❌ Before (Step 1 Unoptimized HTML)

Pure static vertical block flow. The navigation was a plain inline paragraph with pipe delimiters (|) that scrolled away out of sight immediately.

<nav> <p><a href="#about">About</a> | <a href="#education">Education</a></p> </nav>

✅ After (Step 2 Enhanced CSS)

Demonstrates 5 core positioning & display models:
• Sticky positioning: position: sticky; top: 0; with glassmorphism blur on the navigation bar.
• Fixed positioning: position: fixed; bottom: 24px; right: 24px; for the quick-switcher pill.
• Relative & Absolute: Badges, verified tags, and decorative glows placed with precision.
• CSS Flexbox: display: flex; justify-content: space-between; for headers and buttons.
• CSS Grid: Multi-column responsive cards (repeat(3, 1fr) and repeat(4, 1fr)).

.site-header { position: sticky; top: 0; backdrop-filter: blur(20px); } .floating-progress-widget { position: fixed; bottom: 24px; right: 24px; } .projects-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 2rem; }
5️⃣ Assignment Step 2.5

Alignment, Spacing & Box Model UX

Implemented

Requirement: "Work on alignment, spacing, and text formatting to improve the user experience."

❌ Before (Step 1 Unoptimized HTML)

Standard HTML margin collapsing, zero padding on sections, unaligned text elements, and content stretching edge-to-edge across wide monitors.

/* No box-sizing or spacing definitions */ * { box-sizing: content-box; }

✅ After (Step 2 Enhanced CSS)

Global box-sizing: border-box reset, an 8-point spacing system (--space-xs to --space-4xl), max-width: 1440px container with auto centering, smooth scrolling offset (scroll-padding-top: 100px), and micro-interactions on buttons.

*, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; } html { scroll-behavior: smooth; scroll-padding-top: 100px; } .container { max-width: 1440px; margin: 0 auto; padding: 0 1.5rem; }
6️⃣ Assignment Step 2.6 (10/10 USP)

Advanced CSS3 Animations, Micro-Interactions & Hardware Acceleration

Distinction USP

Distinction Feature: Butter-smooth 60/120 FPS transitions, keyframe animations, scroll-reading progress tracking, 3D card lift with specular light reflection, and accessible prefers-reduced-motion fallback.

❌ Before (Step 1 Unoptimized HTML)

Zero transitions or animations. Links jumped instantly with no hover feedback. Page was completely static with no scroll response or micro-interactions.

/* No transitions or keyframes */ a:hover { text-decoration: underline; }

✅ After (Step 2 Enhanced CSS)

Engineered 8 distinct animation subsystems:
• Scroll Progress Bar: Fixed GPU-accelerated gradient tracker.
• IntersectionObserver: Staggered entrance animations (reveal, reveal-left, reveal-right, reveal-scale).
• Text Shimmer: Continuous metallic gradient sweep (@keyframes textShimmer).
• Specular Light Sheen: Moving diagonal beam on card hover (::before pseudo-element).
• Radar Ripple: Multi-ring pulse on verified badges (@keyframes radarPulse).
• Spring Physics: Custom cubic-bezier bounce (cubic-bezier(0.34, 1.56, 0.64, 1)).
• Animated Counters: KPI numbers smoothly counting up into view.
• Accessibility: Full @media (prefers-reduced-motion) compliance.

/* Hardware-Accelerated 3D Lift & Specular Light Sweep */ .project-card:hover { transform: translateY(-8px) scale(1.012); box-shadow: 0 24px 50px -15px rgba(200, 168, 130, 0.28); } .project-card:hover::before { left: 220%; }
